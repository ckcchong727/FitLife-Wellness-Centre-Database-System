# FitLife Wellness Centre Database System

## Project Overview
FitLife Wellness Centre Database System is a group academic project developed at Universiti Malaysia Sarawak (UNIMAS). The system is designed to manage wellness centre information and support the organisation of membership and fitness-related records.

## Technologies Used
- PHP
- MySQL / MariaDB
- HTML
- CSS
- SQL

## Key Features
- Membership record management
- Trainer information management
- Fitness programme management
- Class attendance records
- Payment record management
- Database queries for reporting and data retrieval

## Database
The project uses a relational database to store and manage system information. The SQL file included in this repository can be used to set up the database locally.

## How to Run
1. Install XAMPP.
2. Start Apache and MySQL.
3. Copy the project folder into the `htdocs` directory.
4. Open phpMyAdmin and create or select the required database.
5. Import `fitlife_db.sql` into the database.
6. Update `db.php` with your local database configuration.
7. Open `http://localhost/fitlife/` in your browser.
